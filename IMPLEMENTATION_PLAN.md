# Primer — Implementation Plan

Production rebuild of the approved `New-Design/` prototype (17 static HTML pages, brand "Primer") as a React + TypeScript + Vite + Supabase application. **The prototype's HTML/CSS is the visual source of truth — the app must be visually identical.**

## Approved decisions

| Decision | Choice |
|---|---|
| App location | Repo root (`New-Design/`, `temp-design/` untouched as siblings) |
| Backend | Hosted Supabase project (migrations + seed shipped in repo) |
| Lesson content | Markdown (`body_md`), plain-textarea editing in admin, rendered to match `.prose` |
| Seed | Full catalog: 8 categories, 31 subcategories, 120 topics, lessons for all, real articles for JavaScript Basics |

## Stack

React 19 · TypeScript · Vite · React Router v7 (`react-router`) · `@supabase/supabase-js` · TanStack Query · React Hook Form + Zod · `react-markdown` + `remark-gfm` + `rehype-raw`/`rehype-sanitize` (allowlist `div.callout`) · Vitest + Testing Library · Playwright.

Env: `.env` (gitignored) → `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`; scripts also use `SUPABASE_SERVICE_ROLE_KEY`, `SUPABASE_DB_URL`. `.env.example` committed.

## Architecture

```
├─ supabase/migrations/          0001_schema · 0002_rls · 0003_views_functions
├─ supabase/seed.sql             generated by scripts/generate-seed.ts, committed
├─ scripts/                      generate-seed.ts · create-admin.ts · content/javascript-basics/*.md
└─ src/
   ├─ main.tsx  router.tsx  styles/styles.css   (ported verbatim from New-Design)
   ├─ lib/        supabase.ts · queryClient.ts · format.ts · database.types.ts
   ├─ components/ icons/ · ui/ (Toast, Modal, Dropdown, Tabs, Switch, Badge, Progress…) · layout/
   ├─ features/   auth/ · catalog/ · learning/ · admin/
   └─ data/       keys.ts · catalog.ts · learning.ts · admin.ts   (TanStack Query hooks)
```

Rules: `styles.css` ported near-verbatim with identical class names so JSX transcribes 1:1 from the prototype; self-hosted fonts; guest/member variants conditionally rendered from the session (fake provider in M0, real in M3, same `useAuth()` interface); `/admin/*` lazy-loaded; no barrel files; derived values never mirrored into state.

## Routes

`/` · `/categories` · `/categories/:categorySlug` · `/categories/:categorySlug/:subcategorySlug` · `/topics/:topicSlug` · `/topics/:topicSlug/lessons/:n` · `/search?q=` · `/auth` · `/auth/reset` · `/dashboard`* · `/profile`* · `/admin/login` · `/admin/**`† · `*` NotFound.  (* RequireAuth, † RequireAdmin + lazy)

Not-found policy: empty detail query (bad slug, draft-for-guest, unlinked topic) → `.empty` NotFound card; bad lesson `:n` → redirect to `lessons/1`.

## Database

Enums `topic_level`, `topic_status` (draft/review/published). Tables: `profiles` (role + 2 preference flags), `categories`, `subcategories` (cascade), `topics` (subcategory set-null, `sort_order`, generated `search_tsv`), `units`, `lessons` (composite FK to units, global per-topic `sort_order` = URL `:n`, deferrable unique), `lesson_progress` (per-lesson rows; topic % derived), `bookmarks`, `recent_views`. Views `topic_stats`/`category_stats` (security_invoker, published-only). RPCs `dashboard_stats(tz_offset)`, `search_topics(q)`. RLS everywhere: public reads published catalog, members own-row writes, `private.is_admin()` (execute granted to anon+authenticated — policies run as querying role), role escalation blocked via column-level grants. Seed is fail-closed (aborts if learner data exists) and resyncs identity sequences via `setval`.

## Key assumptions (approved)

- Publish switch: ON = published; OFF = draft (preserves `review` if currently set; `review` settable only via seed/DB in MVP).
- Prototype "simulated/prototype" copy removed; marketing numbers (stats strip, path-map labels) stay hardcoded.
- "Remember me" visual-only; terms checkbox required; avatar upload = "coming soon" toast.
- `lesson_progress.minutes` is a snapshot at completion (never recomputed).
- Non-contiguous lesson completion produces gapped done-markers (deviation from prototype's derived-contiguous display).
- Email confirmation disabled in Supabase auth settings for MVP (documented in README).
- Streak uses client-supplied timezone offset.

## Risks

Markdown→`.prose` fidelity (screenshot-diffed in M2) · auth flicker (paint blocked on session) · cascade asymmetry (tested in M1) · sticky sidebars (DOM transcribed 1:1) · hosted drift (all schema via migrations).
